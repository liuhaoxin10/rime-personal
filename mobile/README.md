# 独立手机方案：雾凇拼音＋个人词库

此目录是一套可独立导入的完整 Rime 手机配置，适用于紫毫。它与仓库根目录的电脑配置分开维护。

## 导入与更新

在紫毫添加 GitHub 方案时填写：

- 仓库：`https://github.com/liuhaoxin10/rime-personal`
- 分支：`main`
- 配置目录：`mobile`

默认启用中文九键，也可切换雾凇全拼。以后在该方案详情点击「立即更新」即可获取本目录的新版本。

## 来源与保留的设置

- 原生基础文件来自雾凇拼音精确版本 [`75e6572bebc05b49021e842949ce947882e3e4b2`](https://github.com/iDvel/rime-ice/tree/75e6572bebc05b49021e842949ce947882e3e4b2)。
- 叠加[紫毫官方公开的适配配置](https://hareime.com/rime-ice)，保留原生全拼、九键、英文和 Emoji 设置，以及词典名 `rime_ice`。
- 编程、数据结构、AI/机器学习、数学四套个人词库附加在原生词表之后；遇到重复词条时保留前面的原生权重。
- 九键 `444` 增加「哈哈哈」快捷短语。完整拼音 `424242` 也能输入「哈哈哈」。
- 不包含电脑的全局键盘设置、置顶补丁、误拼补丁、用户学习记录或实验语法模型。

本配置可以保留紫毫的原生词库和方案结构，但不能保证手机九键与电脑全拼的整句首选一致。已知「这很贵了」在紫毫原生九键上也可能出现不准确的首选，本配置没有宣称解决该客户端的整句消歧问题。
