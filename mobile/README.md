# 紫毫手机词库

此目录只给紫毫叠加词库，不包含 `default.custom.yaml` 或任何 `.schema.yaml`。紫毫负责键盘布局、九键分词、候选算法和整句模型；电脑的键盘设置、置顶规则和容错补丁不在此目录中。

GitHub 仓库为 `liuhaoxin10/rime-personal`，分支 `main`，配置目录填写 `mobile`。导入后部署并启用，再在紫毫中选择九键。电脑继续使用仓库根目录，不导入本目录。

主词典为 `custom_rime_ice`，包含当前雾凇中文词表和四套个人专题词库。`personal_phrase_t9.txt` 将数字快捷码 `444` 优先设为「哈哈哈」，不影响完整拼音输入其他词。

这不是通用的独立 Rime 方案包：它依赖紫毫先部署内置雾凇方案及其英文、Lua、OpenCC 等资源，随后叠加本目录。

已确认紫毫内置九键和现有本机 Rime 九键在「这很贵了」一例上都有整句判断偏差。本目录不承诺修复客户端的所有九键整句问题。输入时可以使用「选拼音」锁定音节，或分段选词。

用户学习记录不上传到公开仓库。
