# 独立手机方案：雾凇拼音＋个人词库

此目录是一套可独立导入的完整 Rime 手机配置，适用于紫毫。它与仓库根目录的电脑配置分开维护。

## 导入与更新

在紫毫添加 GitHub 方案时填写：

- 仓库：`https://github.com/liuhaoxin10/rime-personal`
- 分支：`main`
- 配置目录：`mobile`

默认启用中文九键，也可切换雾凇全拼。以后在该方案详情点击「立即更新」即可获取本目录的新版本。

## 来源与保留的设置

- 输入方案和配套资源基于雾凇拼音精确版本 [`75e6572bebc05b49021e842949ce947882e3e4b2`](https://github.com/iDvel/rime-ice/tree/75e6572bebc05b49021e842949ce947882e3e4b2)。
- 中文词表单独更新到雾凇官方 [`da1fbe6`](https://github.com/iDvel/rime-ice/tree/da1fbe602e38f26db846fa10120ee64c2b0324c0/cn_dicts)（2026-10-05）。六张词表的文件大小和哈希见 [`VOCABULARY_SOURCES.txt`](VOCABULARY_SOURCES.txt)。
- 叠加[紫毫官方公开的适配配置](https://hareime.com/rime-ice)，保留原生全拼、九键、英文和 Emoji 设置，以及词典名 `rime_ice`。
- 编程、数据结构、AI/机器学习、数学四套个人词库继续保留，共445条，与基础词表共同参与排序；表的导入位置不保证所有重复词都采用基础词频。
- 手机九键连续按 GHI 键（数字 `4`）时，每次对应一个「哈」：`4` →「哈」，`44` →「哈哈」，`4444` →「哈哈哈哈」，也兼容连续输入 `h`。只在整段都是重复键时生效，原有候选保留。
- 手机九键单按 MNO 键（数字 `6`），或划出小写 `m` 时，前两个候选依次为「吗」「么」。继续输入完整拼音时按正常词库匹配。
- 手机九键优先短语：`9366352`（`zen me la`）→「怎么啦」。完整拼音 `424242` 也能输入「哈哈哈」。
- 手机习惯读音：支持用 `shen mo` 输入「什么」，也支持 `wei shen mo`、`gan shen mo`；原来的 `shen me` 读音保留。习惯读音单独放在 `cn_dicts/personal_readings.dict.yaml`。
- 手机日常搭配单独放在 `cn_dicts/personal_chat.dict.yaml`：补充「很贵了」，并保留「明天早上再说」「明天晚上再说」两个完整表达。
- 不包含电脑的全局键盘设置、置顶补丁、误拼补丁、用户学习记录或实验语法模型。

本配置可以保留紫毫的原生词库和方案结构，但不能保证手机九键与电脑全拼的整句首选一致。九键中 `zao` 和 `wan` 都是 `926`，「早上」与「晚上」即使完整输入拼音仍然同码，需要结合候选选择意图。

原雾凇文件的作者信息与 GPLv3 LICENSE 均保留。

## 2026-10-23 手机实测反馈调整（v2026.10.23）

用户提供的20题手机首选有18题与目标一致；两处偏差是「这很贵了」和「明天早上再说」。原始反馈保存在 `tools/vocabulary_validation/phone-report-2026-10-23.json`，手机的学习记录和客户端纠错状态不在本机测试范围内。

- 补充自然搭配「很贵了」，权重1000，参与正常组句；不修改「很贵」「都会」等原词频。
- 以相同权重100补充「明天早上再说」「明天晚上再说」。两句话的九键码完全相同；本机保留「明天晚上再说」首选，使「明天早上再说」完整表达出现在第二候选，不将同码两种意图都计为首选修复。

本机独立部署后，20题精确首选由17/20变为18/20；其中「我刚下课」在手机上正确，本机仍给出「我刚下了」，两种环境的结果不能直接混为手机准确率。原73项固定回归仅「这很贵了」改善，其余首选不变；20项邻近对照无新增退化。结果见 `tools/vocabulary_validation/results-2026-10-23.json`。

本轮修改随 [v2026.10.23](https://github.com/liuhaoxin10/rime-personal/releases/tag/v2026.10.23) 发布。手机在原有 `mobile` 方案中「立即更新」并部署启用后，还需复测实际候选效果。

## 2026-10-22 词库更新验证

六张词表相对上一版净增589条记录，其中基础词表106条、扩展词表35条、Tencent词表448条。九键方案、英文、Lua、个人词条和快捷短语保持原样。

本机固定输入对照使用60条新写日常句、10个专业词和3个历史例子。当前版与最新雾凇版均为日常42/60、专业10/10、历史2/3，73条的首选文本完全一致。它是精确目标短语匹配的观察性回归，不代表手机总体准确率。另有22条既有用例，两版均19/22。

同时比较了白霜和万象Lite的词库数据，保留紫毫九键方案配置。白霜核心日常46/60，但8项改善伴随4项退化；白霜默认全词表44/60，万象Lite38/60。此轮选用最新雾凇词表，不将实验候选设为默认。测试集及逐例结果保存在仓库 `tools/vocabulary_validation/`。
